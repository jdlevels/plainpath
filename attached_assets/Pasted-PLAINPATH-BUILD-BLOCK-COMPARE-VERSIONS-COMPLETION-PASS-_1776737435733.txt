==================================================

Add explicit CTA in Compare Versions session:
“Open in PDF Editor”

Behavior:
- Manager can hand off rejected diffs and/or explicitly selected diffs into PDF Editor
- PDF Editor must open the REVISED document, not the original
- Rejected diff IDs and mapped regions must carry over
- PDF Editor must preload visible marked zones for correction
- Compare Versions remains read-only and does not mutate the document
- Avoid fragile query-only state
- Prefer a formal handoff payload/session linkage if needed

Required outcome:
Compare Versions creates a clean handoff context that PDF Editor can load safely and deterministically.

You must define and implement the exact data contract.

Data contract must include, at minimum:
- handoff id
- compare session id
- revised document/file reference
- selected diff ids
- mapped page/region data needed by PDF Editor
- source tool = compare-versions
- created at timestamp
- optional consumed/opened timestamp if useful

Guidance:
- Do not create messy architecture coupling between Compare Versions and PDF Editor
- Use a formal backend-backed handoff record if that is the cleanest solution
- PDF Editor should be able to fetch handoff context by id and initialize itself from it
- Keep Compare Versions read-only

Also add:
- clear UI affordance for handoff
- sensible empty-state behavior when no rejected/selected diffs exist
- safe fallback if handoff payload is invalid or stale

At the end of implementation, explicitly document:
- the exact handoff payload shape
- where it is stored
- how PDF Editor resolves it
