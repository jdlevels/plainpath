2. Autosave semantics
Do not persist every drag/move/resize frame.
Use this rule:
- click/place actions: save immediately
- typing: debounced save
- drag/move/resize: local live update during interaction, persist on interaction end (mouse-up / drag-end)

3. Highlight definition
Lock “highlight” to mean translucent overlay rectangle only.
It is not text-aware highlighting bound to extracted PDF text.

4. Scroll sync scope
Do not treat exact left/right synchronized scrolling as a Slice 1 blocker.
Slice 1 may use independent scrolling.
Loose visible-page sync can be deferred to a later polish slice.

5. Intake pattern
PDF Editor must follow the PlainPath intake rule from day one:
- user uploads/selects PDF
- selected file card is shown
- file can be removed/replaced via X/remove control
- tool waits in a pre-run confirmation state
- user explicitly clicks “Open in PDF Editor”
- only then is the session created/opened
