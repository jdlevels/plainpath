==================================================
PRIMARY PRODUCT RULE
==================================================

Detection can be automatic.
Redaction must NOT be automatic.

PlainPath should:
1. detect likely sensitive information
2. show suggestions to the user
3. let the user choose exactly what to redact
4. only apply redaction after the user clicks:
   "Apply selected redactions"

No permanent redaction should happen before user approval.
