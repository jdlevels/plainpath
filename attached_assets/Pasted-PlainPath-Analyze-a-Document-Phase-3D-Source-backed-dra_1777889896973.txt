Phase 3D requirements:

1. Enrich completion object generation

Update the deterministic completion parser so each CompletionObject has stronger fields.

Target fields:

plainEnglishExplanation:
Explain what the item means in direct plain English.

whatToDo:
Give the user a concrete next step.

whereToGetThis:
Tell the user where to get or confirm the item when source data supports it.

sourceQuote:
Use a direct quote/snippet from the uploaded document when available.

dueDate:
Use only if the document clearly states an actual date or calculable date.

trigger:
Use when the document states timing such as:
- within 15 calendar days
- before submission
- upon signing
- after receipt
- before start date
- within 30 days
- before deadline

2. Keep source discipline strict

Do not fabricate official forms.
Do not invent exact office names unless present in the document.
Do not invent URLs.
Do not invent legal conclusions.
Do not invent dates.

Use safe guidance language:
- “Contact the issuing office listed in the document.”
- “Confirm with the school, employer, provider, agency, or organization that issued this document.”
- “Use the portal, office, or contact method named in the document if one is provided.”
- “PlainPath did not find a specific source for this.”

3. Type-specific enrichment rules

For action_step:
- plainEnglishExplanation: why this action matters
- whatToDo: concrete user action
- whereToGetThis: where to confirm or complete the action
- sourceQuote: supporting clause/sentence

For required_document:
- plainEnglishExplanation: why the document is needed
- whatToDo: gather, verify, or upload the document
- whereToGetThis: likely issuer only if supported by source
- sourceQuote: supporting source text

For missing_document:
- plainEnglishExplanation: the document appears referenced or required but was not uploaded
- whatToDo: request or locate the missing item
- whereToGetThis: official issuer/contact source if available; otherwise safe fallback
- sourceQuote: quote that references the missing document

For signature_needed:
- plainEnglishExplanation: who/what appears to require signature
- whatToDo: confirm signer, sign location, and submission method
- whereToGetThis: official form/source guidance only if supported
- sourceQuote: signature clause or signature block

For deadline:
- plainEnglishExplanation: what timing requirement exists
- whatToDo: complete the related item before the timing window
- trigger: timing phrase from the source
- dueDate: only if explicit or safely calculable from a known date
- sourceQuote: deadline sentence

For risk:
- plainEnglishExplanation: why this risk matters
- whatToDo: ask for clarification, verify terms, or pause before relying on the document
- sourceQuote: risk-triggering clause
- avoid legal advice language

For question_to_ask:
- plainEnglishExplanation: why this question should be asked
- whatToDo: ask the issuing party or responsible office
- whereToGetThis: where to ask if source identifies a contact/entity
- sourceQuote: source text that made the question necessary
