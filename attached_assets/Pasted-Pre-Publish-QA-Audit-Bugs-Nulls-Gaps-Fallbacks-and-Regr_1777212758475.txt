Find bugs, null/undefined risks, broken flows, missing fallbacks, stale copy, route issues, auth issues, modal issues, and obvious production blockers before publishing.

Important:
Do not redesign.
Do not refactor.
Do not add new features.
Do not change layout architecture.
Do not touch database, migrations, Stripe/payment, or schema.
Do not apply database migrations.
Only make code changes if a true blocker, runtime crash, null/undefined bug, broken route, broken auth flow, broken modal behavior, or broken user-facing action is found.
