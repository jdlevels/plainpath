PRODUCT POSITION
Compare Versions is a first-class standalone PlainPath tool.
It is not a generic diff utility.
It is a manager/supervisor audit and verification workspace.

CORE USE CASE
A manager/supervisor uploads:
1. the original approved document
2. the revised document returned by an intern, contractor, vendor, or outside company

The system scans both documents using the ORIGINAL as the standard/baseline and shows exactly what changed.

The goal is to let the manager immediately see:
- what was added
- what was removed
- what was changed
- what moved
- what changed unexpectedly
- what may be high-risk

This is especially important for:
- SOPs
- manuals
- policies
- contracts
- compliance docs
- vendor-delivered revisions

LOCKED PRODUCT RULES
1. Compare Versions is a standalone tool with:
   - its own card/button in the authenticated app
   - its own entry in the Tools dropdown
   - its own public-site explanation
   - its own demo entry later
2. The workspace is document-first and split-screen:
   - left pane = original document
   - right pane = revised document
3. Both panes must visibly render the documents, not just abstract text summaries
4. The comparison starts only when the user explicitly presses a Scan / Compare button
5. The original document is the baseline/source of truth
6. Manager notes/checklist must be part of the comparison session
7. Compare Versions is not PDF Editor:
   - it does not perform full editing
   - it verifies changes
8. It should eventually pair naturally with PDF Editor, but that integration is not part of this blueprint unless explicitly stated

V1 TOOL FLOW
1. User enters Compare Versions
2. Upload/select original document
3. Upload/select revised document
4. Optional: add manager notes / review checklist
5. Explicitly press Scan / Compare
6. System compares both documents
7. Results appear as:
   - side-by-side synchronized visual comparison
   - change summary
   - changed pages/regions
   - severity grouping
   - navigation to each difference
