Requirements:

1. Upgrade source evidence section in ItemDetailDrawer

Current drawer has source evidence, but it needs to feel more premium and more obvious.

Replace or enhance the existing Source Evidence area with a dedicated section:

Title:
“Source Evidence”

Subtitle:
“PlainPath found this guidance in your uploaded document.”

When item.sourceQuote exists:
- show source quote in a visually distinct evidence card
- use quotation styling
- include a small label: “From your document”
- include a source icon or document icon
- keep the quote readable but visually secondary
- avoid huge red/alert styling
- allow long quote text to wrap cleanly
- if quote is very long, clamp to 4–6 lines with a “Show full quote” / “Hide quote” toggle

When item.sourceQuote does not exist:
- show fallback text:
“PlainPath did not find a direct quote for this item. Review the uploaded document manually before acting.”
- style as neutral/amber caution, not an error
- do not hide the section

2. Add “Copy source quote” button

If sourceQuote exists:
- add a small button: “Copy source”
- copies only the source quote
- show copied confirmation
- should not interfere with existing “Copy message” button
- deterministic, no AI

If navigator.clipboard is unavailable:
- fail gracefully
- do not crash

3. Make source-backed vs fallback status obvious

In the drawer header or Source Evidence section, add a small status chip:

If sourceQuote exists:
“Source-backed”

If no sourceQuote:
“Needs manual review”

Design:
- Source-backed = calm green/emerald chip
- Needs manual review = amber/neutral chip
- Do not use alarming full red treatment for missing source quotes

4. Show trigger/deadline source relationship

If item.trigger exists, show it near the source section as:

“Timing trigger: [trigger]”

If item.dueDate exists, show:

“Date found: [dueDate]”

If both exist, show both.

These should be compact metadata rows, not large cards.
