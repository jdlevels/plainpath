2. Add guided questions per document type

Each template should include guided questions that help prefill the document.

Examples:

SOP guided questions:
- What process does this SOP explain?
- Who is responsible for following it?
- When should this process be used?
- What tools, materials, or systems are needed?
- What are the steps in order?
- What mistakes or safety concerns should the user avoid?
- What records should be kept?
- Who approves or reviews this SOP?

Policy guided questions:
- What rule or standard does this policy establish?
- Who must follow it?
- What actions are required?
- What actions are prohibited?
- Are there exceptions?
- What happens if the policy is not followed?
- How often should it be reviewed?

Onboarding guided questions:
- What role or department is this for?
- What should the employee do on day one?
- What systems need access?
- What training is required?
- Who are the key contacts?
- What policies must be reviewed?
- What confirms onboarding is complete?

3. New document creation flow

In pages/Builder/New.tsx, create a premium flow:

Step 1: Choose document type
- Show template cards for all 8 structured templates
- Include “Start from blank”
- Show short description for each

Step 2: Guided questions
- After template selection, show the relevant guided questions
- User can answer some or all questions
- Answers are optional
- Include helper text: “Answer what you know. PlainPath will structure the draft around your inputs.”

Step 3: Create draft
- Generate a BuilderContent object using:
  - selected document type
  - guided answers
  - predefined sections
  - placeholder text where answers are missing
- Use existing builder save/create logic
- Do not create a new database table
- Do not add migrations

4. Generated draft behavior

The draft should not be blank.

Each selected template should create:
- document title
- section headings
- helpful placeholder text
- checklist blocks where appropriate
- table blocks where appropriate if already supported
- revision history block where appropriate
- footer/document control section where appropriate

Examples:
For SOP, create a step-by-step procedure section with placeholder steps.
For onboarding, create first-day checklist and training checklist blocks.
For safety manual, create hazard reporting and emergency procedure sections.
For incident report, create timeline and corrective action sections.
For checklist, create checklist blocks immediately.
