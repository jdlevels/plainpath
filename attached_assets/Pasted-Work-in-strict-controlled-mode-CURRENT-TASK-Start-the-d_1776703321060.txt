GOAL
Convert Document Builder from the current single-pane editor into a split-screen Builder workspace.

TARGET LAYOUT
Document Builder should become:

LEFT PANE
- live blank-page document preview
- realistic document page proportions (Letter or A4 style)
- render the current Builder content as a real page preview
- read-only preview in this slice
- no editing controls inside the page preview
- neutral/dark surrounding stage is acceptable, but the page itself must read clearly as a document page

RIGHT PANE
- existing Builder controls
- section list / section controls
- block controls
- block editing inputs
- document settings already in scope
- keep the editing system structured and guided

CORE RULES
1. The left pane must render from the same current Builder content state already being autosaved.
2. No new Builder data model may be introduced for this slice.
3. No drag-anywhere canvas behavior.
4. No freeform desktop-publishing behavior.
5. The page preview must update live as content changes.
6. The preview should help the user judge spacing, hierarchy, section flow, and readability.
7. The right pane remains the only editing surface.

IMPLEMENTATION APPROACH
Use the existing Builder content object as the source of truth.
Build a preview renderer that consumes the current section/block structure and renders:
- headings
- paragraphs
- bullet lists
- numbered lists
- checklists
- key-value blocks
- notes/callouts
- dividers
- tables

The preview renderer should be a document-output renderer, not a second editor.
