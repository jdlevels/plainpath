CONTEXT
PlainPath now has a locked workspace rule for document-heavy tools:

- document-heavy tools should render a realistic US Letter page surface on desktop when possible
- pane sizing must prioritize document legibility
- split-screen alone is not sufficient
- the document surface must feel comfortably readable and workable, not thumbnail-sized
- on smaller screens/mobile, preserve page proportions and adapt responsively
- desktop remains the primary simultaneous split-screen experience

Builder, Redact, and Digital Signature now follow this rule.

PRODUCT REQUIREMENT FOR PDF EDITOR
PDF Editor must be a true split-screen tool from day one.

Left pane:
- original PDF
- read-only reference
- scrollable
- visually dominant
- large enough for real reading and comparison

Right pane:
- editable working copy / edit controls
- the place where modifications are applied and managed

The user must never edit blind.
