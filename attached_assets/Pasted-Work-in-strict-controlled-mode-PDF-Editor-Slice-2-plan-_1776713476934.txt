LOCKED IMPLEMENTATION RULES

1. Editing surface
- Left pane stays ORIGINAL / read-only
- Right pane is the only editable working copy

2. Save UX
- Save button always visible
- Save states:
  - idle
  - unsaved
  - saving
  - saved
  - error ("Save failed")
- unsaved state visually highlights the Save control
- explicit Save click persists immediately

3. Save timing
- click/place new op: immediate save
- drag/move/resize: save on interaction end only
- typing: debounced 800ms
- timed autosave: every 60s if state is unsaved

4. Save-failure behavior
- preserve all local edits in memory
- keep Save button enabled
- allow immediate retry
- do not discard work

5. Upload/storage
- store source PDF as bytea/binary, not base64 text
- validate upload server-side as PDF-only
- enforce file size limit
- reject unreadable/invalid uploads with clear error

6. Session list
If /pdf-editor shows session list, keep it minimal only:
- title/file name
- updated time
- open existing session
No delete/archive, no search, no filter UX.

7. Page count
- page_count may be set once after first render/load
- do not treat it as a general mutable field
- if using PATCH /page-count, only set when null

8. Undo/redo persistence
- saved current ops restore on reload
- undo stack history itself does not persist across reload in Slice 2
- do not pretend otherwise
