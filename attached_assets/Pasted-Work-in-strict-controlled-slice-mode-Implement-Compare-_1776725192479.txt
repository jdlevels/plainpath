2. Backend routes

Create:
- artifacts/api-server/src/routes/compare-versions/index.ts

- artifacts/api-server/src/app.ts

Reuse the same server-side object-storage wrapper pattern already used by PDF Editor.
If needed, extend the wrapper, but do not break PDF Editor.

Object paths:
- compare-versions/{userId}/{sessionId}/original.pdf
- compare-versions/{userId}/{sessionId}/revised.pdf

Required routes for Slice 1:

POST /api/compare-versions/sessions
Purpose:
- accept multipart/form-data
- originalFile
- revisedFile
- optional title
- optional managerNotes JSON
- validate both files are PDFs in V1
- upload both to object storage
- create session record
- return created session metadata

GET /api/compare-versions/sessions
Purpose:
- list current user’s sessions
- most recent first
- return: id, title, status, createdAt, updatedAt, originalFileName, revisedFileName

GET /api/compare-versions/sessions/:id
Purpose:
- return one session metadata only
- no rendering
- no diff processing
- include persisted manager_notes

Validation rules:
- both files required
- both must be MIME application/pdf
- reject .docx/.txt/images in V1 with explicit error message
- max 50 MB per file
- no silent coercion or conversion
