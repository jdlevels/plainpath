PlainPath Launch Stabilization — Remove E-Signature Feature, Keep Signature Line / Date Field Blocks Only

Decision:
PlainPath will not include e-signature, digital signature, Dropbox Sign, send-for-signature, signing workflows, signature routing, signature envelopes, or signature status tracking.

However, PlainPath Document Builder IS allowed to include basic document layout fields:
- Signature line
- Date line
- Printed name line
- Approval/sign-off line

These are not e-signature features. They are simple printable document fields that users can place on the page.

Goal:
Fully remove the unfinished e-signature feature while preserving or adding simple document-builder field blocks for signature/date placement.

- Digital Signature tool
- E-signature tool
- Send for Signature
- Sign document workflow
- Signature routing
- Signature envelopes
- Signature status tracking
- Dropbox Sign integration
- Dropbox Sign privacy references
- Signature API endpoints
- Signature webhooks
- Signature route
- Signature page/component
- Signature modal
- Signature buttons that launch signing
- Signature cards
- Signature CTAs
- Signature menu items
- Signature “Coming Soon” feature references
- Signature helper text connected to signing workflows
- Signature environment variable references if only used for e-signature
- Any direct route access to /signature or related paths

Keep / allow only:
- A simple Signature Line field/block inside Document Builder
- A simple Date Line field/block inside Document Builder
- Optional Printed Name Line field/block
- Optional Approval / Sign-off Line field/block
- These fields should be printable/static document elements only
- These fields should not send, request, verify, authenticate, track, or process signatures

Important distinction:
A “Signature Line” block is allowed.
A “Send for Signature” feature is not allowed.

- contract text

- template language
- legal/contract clauses
- normal printed signature line fields
- file icon usage that is generic and not connected to the removed feature

4. Document Builder allowed field behavior
Inside Document Builder, allow users to insert:
- Signature line
- Date line
- Printed name line
- Approval/sign-off line

Behavior:
- User can place the line on the left document canvas.
- User can move it.
- User can resize it if supported.
- It snaps to the invisible grid.
- It saves/reloads as a normal document field.
- It does not send anything to any third-party service.
- It does not create a signing request.
- It does not track signer status.
- It does not verify identity.
- It does not collect biometric/signature data.
- It is simply a visible line/label for printed/manual signing.
