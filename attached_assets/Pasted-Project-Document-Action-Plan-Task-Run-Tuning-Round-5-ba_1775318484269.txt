PRIORITY 1 — IRS / FEDERAL IMPERSONATION DOMAIN PATTERN
-----------------------------------

Problem:
The engine is still under-scoring certain IRS/federal impersonation documents when they use constructed private `.com` payment/contact domains.

Required tuning:
Generalize the public-issuer/private-domain mismatch logic so it also covers IRS/federal/tax/revenue/resolution-center phrasing.

Examples:
- irs-tax-resolution-center.com
- domains that combine federal/tax authority language with a private `.com`
- names containing IRS, tax, revenue, treasury, resolution, collections, enforcement, payment center, etc., without `.gov`

Target behavior:
If a document claims to be from a federal/tax authority but the primary contact/payment domain is a private `.com`, Authenticity Risk should materially increase.

Recommended effect:
These should usually move into a clearly suspicious/high-scam band when paired with payment pressure.

-----------------------------------
PRIORITY 2 — CRYPTO / DIGITAL ASSET PAYMENT SIGNAL
-----------------------------------

Problem:
Government-style scam notices listing crypto / digital asset transfer as an approved payment method are not being scored harshly enough.

Required tuning:
Add cryptocurrency / digital asset payment as a standalone high-risk authenticity signal.

Examples to catch:
- verified digital asset transfer
- crypto payment
- bitcoin / ethereum / USDT payment
- wallet transfer
- digital asset authorization as payment

Goal:
This signal should materially raise Authenticity Risk even before other scam signals are compounded.

Recommended effect:
+20 to +25 authenticity contribution when present in suspicious/government-style payment contexts.

-----------------------------------
PRIORITY 3 — REFERENCE IDENTIFIER DETECTION FIX
-----------------------------------

Problem:
Structural findings are incorrectly claiming “no traceable reference number” when valid identifiers are present.

Required tuning:
Extend identifier detection to recognize:
- Case ID
- File No.
- File Number

Target behavior:
If one of these identifiers is present, structural findings should not say there is no traceable reference number.

Apply to:
- IRS/federal-style notices
- debt collection notices
- any similar document with case/file references
