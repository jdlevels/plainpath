--------------------------------------------------
1. ADD “START HERE” POST-ANALYSIS BANNER
--------------------------------------------------

When analysis results load, show one contextual guidance banner near the top of the results content.

The banner should recommend the most urgent next section based on available findings.

Priority logic:
1. If risks exist and severity is high/critical:
   “Start here: High-risk issue found — review Risks & Notes first.”
2. Else if deadlines exist:
   “Start here: Deadline found — review Deadlines first.”
3. Else if required documents exist:
   “Start here: Required documents found — review Required Docs first.”
4. Else:
   “Start here: Review the Overview, then follow the Action Pack.”

The banner should include a CTA button:
- “Review Risks”
- “Review Deadlines”
- “Review Required Docs”
- “View Overview”

Clicking the CTA should open the correct tab.

Keep styling premium:
- subtle dark card
- colored left accent based on urgency
- small icon
- not too tall
- mobile responsive

“0/6 steps reviewed”

“Progress: 0%”

The current header already shows progress, but make it more useful by tying it to Action Pack/checklist completion if available.

Do not make this visually loud.
Keep it compact near Save/Export.

--------------------------------------------------
3. SURFACE DETECTED DOCUMENT TYPE IN HEADER
--------------------------------------------------

Show detected document type near the title.
