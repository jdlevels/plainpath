Requirements:

1. Replace Complete placeholder with real CompleteModeView

When activeMode === "complete", render a focused Complete mode summary.

The screen should answer:

- How much is complete?
- What is done?
- What remains?
- What requires manual review?
- What still needs a source check?
- What is ready for the final packet later?

2. Completion header

At the top show:

Title:
“Complete Your Document Plan”

Subtitle:
“Review what is done, what is still open, and what needs manual confirmation before you submit or rely on this document.”

Show progress:
- X/Y complete
- percentage
- progress bar
- status label

Status labels:
- 0%: “Not started”
- 1–49%: “In progress”
- 50–99%: “Almost ready”
- 100%: “Ready to compile”

Do not say “ready to submit” because PlainPath does not control official submission.

3. Summary cards

Add 4 compact summary cards:

A. Completed
- count of done items

B. Still Open
- count of not-done items

C. Needs Manual Review
- count of items without sourceQuote

D. Source-backed
- count of items with sourceQuote

Use calm colors:
- completed = emerald
- open = neutral/blue
- manual review = amber
- source-backed = green/blue
No heavy red unless critical risks are still open.

4. Grouped checklist sections

Render grouped sections from completionObjects:

- Completed Items
- Still Open
- Needs Manual Review
- Critical / High Priority Open Items

Each item row should show:
- done/not done state
- title
- type label
- priority
- source-backed or needs-review chip
- Details button

Clicking Details should open the existing ItemDetailDrawer.
Do not create a second drawer.

5. Empty states

If no items completed:
“Nothing has been marked complete yet. Go to Plan mode and start working through your document checklist.”

If no open items:
“All checklist items are marked complete. Review the source evidence and generate your packet in the next step.”

If no manual-review items:
“All items currently shown have source evidence.”

If no critical/high open items:
“No critical or high-priority open items remain.”

6. Navigation actions

Primary:

- lands on the most useful Plan tab if possible
- if there are open critical/high items, go to Risks or Checklist based on first open item type
- otherwise go to Checklist

Secondary:

Disabled/future action:
