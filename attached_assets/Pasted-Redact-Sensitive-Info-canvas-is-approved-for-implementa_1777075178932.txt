- Empty State
- Processing State
- Completed Redaction Review
- Sensitive item active / highlighted state
- Redaction Preview State
- Low Confidence State
- Error State
- Mobile Redactions View
- Mobile Document View

3. The left document panel must show the paper being redacted.

Required behavior:
- Show uploaded document as a page/paper surface
- Show detected sensitive items highlighted in Original View
- Show black redaction blocks over selected items in Redaction Preview
- When a user clicks a detected item in the right panel, scroll to that item on the document
- Highlight the active item with a visible source/selection ring
- Keep the original document unchanged
- Export creates a separate redacted copy

4. Include Original View / Redaction Preview toggle.

Original View:
- shows detected-item highlights
- lets the user inspect what PlainPath found

Redaction Preview:
- shows black redaction blocks over selected sensitive items
- lets the user preview the final redacted copy before export

C. Suggested Redactions
D. Redaction Categories
