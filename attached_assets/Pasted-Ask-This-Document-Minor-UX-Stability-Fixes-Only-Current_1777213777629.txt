Ask This Document — Minor UX + Stability Fixes Only

Current live state:
Ask This Document is now loading PDFs correctly and chat answers are working. The PDF viewer looks much better.

Remaining issues:

1. Chat message layout:
When the user asks a question, the user question appears near the top/right but the answer does not feel clearly grouped. The chat should show a clear conversation flow:
- User question in its own message bubble/box
- AI answer below it in its own bordered answer box/card
- Both should remain visible in the chat panel
- The newest answer should be easy to read and visually separated

2. Source/highlight behavior:
When AI answers a question about the document, it should try to help the user locate the supporting section in the PDF/document viewer.
Expected behavior:
- If the answer references a document section, clause, paragraph, or extracted source, highlight or focus the matching location in the left document panel.
- For PDF uploads, if exact PDF text-coordinate highlighting is already available from the existing PDF viewer, use it.
- If exact coordinate highlighting is not available, implement a practical fallback:
  - identify the best matching extracted section/text snippet
  - scroll the left panel to that section/page if possible
  - show a visible source banner or highlighted source card above/in the document viewer saying something like:
    “Source used for this answer”
  - do not fake precision if exact PDF coordinates are unavailable
- If no source can be matched, show:
  “No exact source location found for this answer.”

3. Page reset / lost uploaded document:
After the PDF was loaded for about 1 minute, the page flashed/reset and the uploaded document disappeared. User had to upload the document again.
This must be fixed.
Expected behavior:
- Once a document is loaded, the Ask This Document workspace must not reset by itself.
- Chat errors, token refreshes, API failures, timers, re-renders, or background effects must not clear:
  - uploaded PDF file/object URL
  - analysis object
  - extracted text
  - chat messages
  - selected mobile tab
  - ready phase
- Only explicit user action should reset the workspace:
  - back button
  - remove/change document
  - start over button
  - new upload
- If an error occurs, preserve the loaded document and show an inline error instead of resetting.
