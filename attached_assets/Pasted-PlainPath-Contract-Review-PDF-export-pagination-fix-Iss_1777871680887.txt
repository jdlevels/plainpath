4. Print CSS requirements

Add or fix print CSS so:

- html, body use auto height for print
- no overflow hidden on the print report
- no max-height on report sections
- no sticky/fixed elements inside the printable report
- cards can break cleanly between pages where needed
- section headings avoid being orphaned at the bottom of a page
- each major section can start cleanly when appropriate

Use CSS patterns like:

@media print {
  html,
  body {
    height: auto !important;
    overflow: visible !important;
  }

  .contract-review-print-report {
    height: auto !important;
    max-height: none !important;
    overflow: visible !important;
  }

  .no-print {
    display: none !important;
  }

  .print-section {
    break-inside: avoid;
    page-break-inside: avoid;
  }

  .print-page-break {
    break-before: page;
    page-break-before: always;
  }
}

Only use break-inside: avoid where it does not force huge blank spaces.
