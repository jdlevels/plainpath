3. Print-only styling

Add scoped print styles for the packet.

Print output should:
- use white background
- use dark text
- hide app navigation/header/sidebar/chrome where possible
- hide mode navigation
- hide drawer overlays
- hide screen-only buttons
- hide “Back to Complete”
- hide “Review Open Items”
- hide “Print / Save as PDF” itself
- hide Details buttons
- hide interactive controls
- show packet title and metadata
- preserve section order A–M
- preserve source evidence quotes
- preserve manual-review notes
- preserve final disclaimer

Use print class names so the styles are tightly scoped, for example:
- .packet-print-root
- .packet-screen-actions
- .packet-print-section
- .packet-print-only
- .packet-no-print

Avoid broad @media print rules that could damage Contract Review or other pages.
