1. Replace Compile placeholder with real CompileModeView

Title:
“Document Action Packet”

This is a preview only.

2. Packet status header

Show:
- Document title
- Document type/category if available
- Completion count: X/Y complete
- Completion percentage
- Packet status label

Status labels:
- 0%: “Not started”
- 1–49%: “In progress”
- 50–99%: “Partially complete”
- 100%: “Ready for final review”

Do not use “ready to submit.”

3. Packet sections

Render the packet in this order:

A. Cover / Packet Summary
- document title
- document type
- generated/preview date
- completion status
- source-backed count
- manual-review count

B. Plain-English Summary
Use existing analysis summary/plainEnglish data if available.
If missing, show:
“PlainPath could not generate a plain-English summary for this document.”

C. Completed Items
Items where completionStatus[id] === true.

D. Open Items
Items not marked complete.

E. Required / Missing Documents
All required_document and missing_document items.

F. Signatures Needed
All signature_needed items.

G. Deadlines / Timing
All deadline items, including dueDate and trigger when available.

H. Risks / Review Before Acting
All risk items.

I. Questions to Ask
All question_to_ask items.

J. Source Evidence Index
List items with sourceQuote.
Each row should show:
- item title
- item type
- source quote preview
- source-backed chip

K. Manual Review Needed
List items without sourceQuote.
Show a neutral/amber note:
“These items did not include a direct source quote. Review the uploaded document manually before acting.”

L. Final Review Checklist
Static checklist:
- I reviewed open items
- I verified source evidence
- I gathered required documents
- I confirmed signatures
- I checked deadlines
- I understand PlainPath is not legal, financial, or professional advice

M. Disclaimer
Use clear, visible copy:
“PlainPath helps organize and explain documents. It does not provide legal, financial, medical, or professional advice. Always verify requirements with the issuing organization before acting.”
