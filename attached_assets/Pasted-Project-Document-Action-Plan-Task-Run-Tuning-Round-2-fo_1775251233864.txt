Project: Document Action Plan
Task: Run Tuning Round 2 for Document Trust Check based on repeated patterns confirmed in Controlled External Pilot Batch 2.

Goal:
Address the two recurring post-tuning patterns now strong enough to justify another tuning pass, while preserving the stable pilot baseline and avoiding unnecessary scope creep.

Confirmed repeated patterns:
1. Document Risk underscoring on non-financing service/subscription contracts
2. Verification Confidence too conservative on legitimate multi-identifier records

Critical constraints:
- Do NOT add new major features
- Do NOT redesign the UI
- Do NOT activate paid features
- Do NOT restore subscription gating
- Do NOT add security rollout
- Do NOT build trusted-entity verification yet
- Keep the current three-score model intact
- Make only targeted tuning changes tied directly to the confirmed repeated patterns

-----------------------------------
TUNING PRIORITY 1
-----------------------------------

Broaden Document Risk for non-financing service/subscription contracts.

Current problem:
Documents with multiple consumer-harm terms outside loan/finance contexts are still scoring too low on Document Risk.

Examples already identified:
- FitLife Gym Membership
- ConnectPro Telecom

Add/strengthen Document Risk handling for:
- early termination fees
- liquidated damages
- auto-renewal clauses
- long notice-window traps
- cancellation barriers
- administrative termination fees
- suspension without notice
- equipment/return fees
- one-sided service remedies
- arbitration/class-action waiver
- recurring billing lock-ins

Goal:
These documents should no longer sit in LOW Document Risk when they contain 4–6 meaningful consumer-harm terms.

-----------------------------------
TUNING PRIORITY 2
-----------------------------------

Raise Verification Confidence for legitimate multi-identifier records when strong evidence is present.

Current problem:
Legitimate documents with multiple identifiers and coherent institutional details are remaining in PARTIAL confidence too often.

Examples already identified:
- Parkview Lease Renewal
- Verizon Phone Bill
- BCBS EOB

Increase positive confidence weighting when the document contains:
- multiple internal identifiers
- consistent dates and amounts
- institutional domain
- office phone / standardized contact details
- coherent sender/issuer identity
- plausible document structure
- no major contradictions

Goal:
Legitimate records with strong internal consistency should move from PARTIAL toward GOOD where justified.
