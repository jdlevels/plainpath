Project: PlainPath
Task: Record the raw screen captures for the homepage narrated product demo first, before finalizing voiceover timing.

Goal:
Capture clean, polished raw footage from the real app so the final voiceover timing can be adjusted to actual product behavior instead of guessing from a script alone.

Important:
Do NOT jump straight to final video editing.
Do NOT finalize the narration timing before the footage is captured.
The correct sequence is:
1. capture real app footage
2. review footage length and pacing
3. then tighten the voiceover to the real visuals

Primary objective:
Produce a complete raw capture set for the product demo covering the three core product lanes:
- Analyze a Document
- Document Trust Check
- Build a Contract

-----------------------------------
CAPTURE PRINCIPLES
-----------------------------------

All footage should be:
- recorded from the real app
- clean and stable
- free of debug/pilot/internal-only UI
- cursor movement smooth and intentional
- no rushed clicking
- no unnecessary pauses
- no visible code/editor panels
- no browser clutter if avoidable
- suitable for a premium homepage product demo

Use the cleanest environment possible:
- full browser/app view of the product only
- no distracting tabs/toolbars if possible
- consistent viewport
- smooth interactions

-----------------------------------
CAPTURE STYLE
-----------------------------------

For each clip:
- keep duration natural
- hold each important state for 2–4 seconds minimum
- avoid frantic mouse movement
- avoid over-scrolling
- if an animation is present, let it complete
- if a result loads, wait for it to settle before moving

Where appropriate, also capture:
- one static clean hold shot
- one slightly interactive walkthrough version

This gives flexibility in editing.
